# 第21届全国大学生智能汽车竞赛：蚂蚁搬家组 Q&A 清洗版

> 来源：`https://zhuoqing.blog.csdn.net/article/details/157686623`
>
> 说明：仅保留规则相关问答，去除页面噪声。

## 1. 2026年2月问答

### QA-202602-01
- 问：蚂蚁搬家组可以自制 RT1021 核心板吗？
- 答：理论上可以；组委会尚无现场检查该板运行 MicroPython 的明确办法，可向组委会提建议。

### QA-202602-02
- 问：辅助车模可以在黄色胶带边界外行走吗？
- 答：可以。

### QA-202602-03
- 问：推杆“水平 10cm”是指方向范围还是推杆长度？
- 答：指推杆长度。

### QA-202602-04
- 问：搬运方式是否只能夹持？可否双车同推？
- 答：夹持与同推本质上均可，需把方案和实验视频说明清楚，便于维护公平。

### QA-202602-05
- 问：辅助车模可以用 OpenART 吗？
- 答：不可以。辅助车模按规则使用 STC。

### QA-202602-06
- 问：无线串口模块是否允许带 MCU？
- 答：不允许，应符合不带额外 MCU 的模块要求。

### QA-202602-07
- 问：摄像头只能放搬运车模上吗？
- 答：辅助车可接普通摄像头（STC 方案）；OpenART 不属于普通摄像头概念。

### QA-202602-08
- 问：场地里用于摆放物品的虚线框会存在吗？
- 答：不会。

### QA-202602-09
- 问：可以使用 UWB 定位吗？
- 答：允许。

### QA-202602-10
- 问：重量罚时按所有车平均还是搬运车平均？
- 答：仅限制搬运车模平均重量。

### QA-202602-11
- 问：搬运车模能碰到未搬运物体吗？物体数量有规定吗？
- 答：可以碰撞未搬运物体；但不允许同时搬运多个物体。物体数量不作固定限制。

### QA-202602-12
- 问：可以使用 HWT101 吗？
- 答：不建议，且其内部含 MCU，可能不符合规则。

### QA-202602-13
- 问：场地尺寸调整后，是否保证每队物品种类和数量一致？
- 答：一致，摆放位置也一致，避免不公平。

### QA-202602-14
- 问：辅助车可否进入 `1m x 1m` 物品区？计时从何时开始？辅助车能否先上场？
- 答：可进入但不可触碰物体；计时从搬运车启动开始；辅助车可先上场。

### QA-202602-15
- 问：推杆可以做增摩处理吗？
- 答：可以。

### QA-202602-16
- 问：沙袋只有红蓝两种颜色吗？
- 答：是，仅红色和蓝色。

### QA-202602-17
- 问：泰迪熊购买链接与尺寸要求不一致怎么办？
- 答：自行寻找小型泰迪熊。

### QA-202602-18
- 问：小熊身上有衣服吗？
- 答：无。

### QA-202602-19
- 问：编码器允许自制吗（如 MT6816）？
- 答：允许。

### QA-202602-20
- 问：某搬运车模控制方案是否允许（含 STC 参与）？
- 答：
  - STC32 可用于搬运车模无刷电机控制；
  - STC32F12K54 可用于辅助车模控制；
  - 若搬运车是有刷电机且无 FOC，不允许使用 STC。

### QA-202602-21
- 问：物体出线后滚动碰到辅助车，算犯规吗？
- 答：允许。

### QA-202602-22
- 问：沙包颜色深浅和数字有要求吗？
- 答：仅红/蓝纯色，无数字；蓝色倾向浅蓝。

### QA-202602-23
- 问：辅助车初始位置可以随意放置吗？
- 答：可以。

### QA-202602-24
- 问：辅助车能否一开始就随意进场？
- 答：可以。

### QA-202602-25
- 问：如何保证物体放置位置一致，地面有坐标点吗？
- 答：只有大体区域，没有固定坐标点。

### QA-202602-26
- 问：`TI-INA219` 与 `CEM5881-M11` 是否可用？
- 答：
  - INA219 芯片可用，但现成模块板不允许直接使用；
  - CEM5881-M11 模块可使用。

### QA-202602-27
- 问：可以不用辅助车、也不用导引光标吗？
- 答：可以，二者均为可选项。

### QA-202602-28
- 问：辅助车模有编程语言限制吗？
- 答：没有限制。

### QA-202602-29
- 问：搬运车上是否允许使用 OpenART 摄像头？
- 答：允许。

## 2. 2026年3月问答

### QA-202603-01
- 问：双车推物时若出现瞬间只有一车接触，是否有效？
- 答：瞬间不同步接触允许；若长期只有一车推动，不符合要求。

### QA-202603-02
- 问：推杆高度有限制吗？
- 答：回复中说明“规则未限定固定高度”，由队伍自行确定合理高度。

### QA-202603-03
- 问：指定摄像模块中存在 C++ 架构，是否允许？
- 答：本组主控模块程序使用 MicroPython 编程。

### QA-202603-04
- 问：可以使用 IMU660RC 吗？
- 答：可以。

### QA-202603-05
- 问：图示模块是否可直接购买并使用？
- 答：可以。

### QA-202603-06
- 问：外形 `<30cm` 是否包含高度？泰迪熊颜色深浅是否有限制？
- 答：
  - 搬运车高度无专门限制；
  - 泰迪熊颜色深浅无特别规定。

### QA-202603-07
- 问：OpenARTPlus 可否焊接排针/转接板（无 MCU）与贴散热片？
- 答：均可以。

### QA-202603-08
- 问：可以使用 UWB 实现两车测距和相对角度吗？
- 答：允许。

### QA-202603-09
- 问：比赛网球上会印字吗？
- 答：大概率不会。

### QA-202603-10
- 问：是否允许使用 `ESP32` 自制无线通信模块？
- 答：不允许；可改用不带可编程特性的其他无线模块。

### QA-202603-11
- 问：计时是从上电开始，还是从搬运车开始移动开始？
- 答：从搬运车离开发车区开始计时，直到最后一个物体搬完结束。

### QA-202603-12
- 问：搬运车上可以放标定物吗？
- 答：可以。

### QA-202603-13
- 问：辅助车模可以加可见光线激光发射器来探测场地吗？
- 答：可以。

### QA-202603-14
- 问：`PMW3901` 模块是否允许使用？
- 答：允许。

### QA-202603-15
- 问：辅助车可以使用多块 `STC`，搬运车可以使用多块 `NXP` 主板吗？
- 答：都可以，数量不限。

### QA-202603-16
- 问：智能视觉与蚂蚁搬家共用场地时，黄色边线宽度怎么处理？
- 答：先按 `5cm` 铺设，后续规则会再统一修改。

### QA-202603-17
- 问：图示推杆方案是否允许？
- 答：认为可以。

### QA-202603-18
- 问：辅助车模必须使用 STC 吗，不能用 MicroPython 吗？
- 答：除非能在 STC 上移植 MicroPython，否则仍按 STC 方案执行。

### QA-202603-19
- 问：图示视觉模块是否可用于蚂蚁搬家？
- 答：可以用于搬运车模。

### QA-202603-20
- 问：规则要求两车之间不能物理连接，那搬运时可以接触吗？
- 答：短暂碰撞可以，但不能形成勾连。

### QA-202603-21
- 问：`PAW3395` 光流传感器是否允许使用？
- 答：允许。

### QA-202603-22
- 问：成绩具体如何计算？
- 答：成绩主看搬运时间，超重仅按规则折算为罚时。

### QA-202603-23
- 问：UWB 模块允许自制吗？
- 答：允许。

### QA-202603-24
- 问：物品之间“最小间距 `10cm`”是按中心距还是边界距理解？
- 答：按边界到边界至少 `10cm` 理解更合理。

### QA-202603-25
- 问：辅助车使用 STC 时可以用 C 语言吗？
- 答：可以。

### QA-202603-26
- 问：图示无线通信模块是否允许使用？
- 答：若模块带 MCU 则不允许。

### QA-202603-27
- 问：比赛开始后，是否还能通过临时拍照等方式给车提供场地信息？
- 答：不应再有人机交互；物品摆放完成后，除开机外不应再对车模进行操作。

### QA-202603-28
- 问：超大尺寸的镂空辅助车方案是否可行？
- 答：官方认为辅助车尺寸应增加限制，例如控制在 `15cm x 15cm` 内，待正文补充。

### QA-202603-29
- 问：成品定位器材可以直接使用吗？
- 答：如果仅用于定位，可以。

### QA-202603-30
- 问：缩微组有没有硬性限重？称重包括哪些部分？
- 答：没有单独限重，重量通过规则折算为罚时；称重包括机械结构、电池、控制板等。

### QA-202603-31
- 问：比赛物品会出现上下叠放吗？
- 答：大概率不会。

## 3. 开发落地澄清（速查）

- 规则主线：双车协同、单件搬运、按最新问答口径完成计时闭环。
- 计时口径：从搬运车离开发车区开始，到最后一个物体搬完结束。
- 平台主线：搬运主控 `NXP-MicroPython`，辅助车 `STC`。
- 模块主线：原则上禁用带额外 MCU 的“智能模块”。
- 交互主线：物品摆好后不应再进行赛时人机交互。
- 场地主线：预赛和决赛障碍配置不同，决赛复杂度更高。
- 间距主线：物品最小间距按边界到边界至少 `10cm` 理解。
- 合规主线：Q&A 可对细则进行解释和补充，工程实现需同步引用。
