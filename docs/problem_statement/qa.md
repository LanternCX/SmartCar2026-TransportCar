# 第21届全国大学生智能汽车竞赛：蚂蚁搬家组 Q&A 清洗版

> 来源：`https://zhuoqing.blog.csdn.net/article/details/157686623`
>
> 说明：仅保留规则相关问答，去除页面噪声。

## 1. 2026年2月问答

### QA-202602-01
- 问：蚂蚁搬家组可以自制 RT1021 核心板吗？
- 答：理论上可以；组委会尚无现场检查该板运行 MicroPython 的明确办法，可向组委会提建议。

### QA-202602-02
- 问：辅助车模可以在黄色胶带边界外行走吗？
- 答：可以。

### QA-202602-03
- 问：推杆“水平 10cm”是指方向范围还是推杆长度？
- 答：指推杆长度。

### QA-202602-04
- 问：搬运方式是否只能夹持？可否双车同推？
- 答：夹持与同推本质上均可，需把方案和实验视频说明清楚，便于维护公平。

### QA-202602-05
- 问：辅助车模可以用 OpenART 吗？
- 答：不可以。辅助车模按规则使用 STC。

### QA-202602-06
- 问：无线串口模块是否允许带 MCU？
- 答：不允许，应符合不带额外 MCU 的模块要求。

### QA-202602-07
- 问：摄像头只能放搬运车模上吗？
- 答：辅助车可接普通摄像头（STC 方案）；OpenART 不属于普通摄像头概念。

### QA-202602-08
- 问：场地里用于摆放物品的虚线框会存在吗？
- 答：不会。

### QA-202602-09
- 问：可以使用 UWB 定位吗？
- 答：允许。

### QA-202602-10
- 问：重量罚时按所有车平均还是搬运车平均？
- 答：仅限制搬运车模平均重量。

### QA-202602-11
- 问：搬运车模能碰到未搬运物体吗？物体数量有规定吗？
- 答：可以碰撞未搬运物体；但不允许同时搬运多个物体。物体数量不作固定限制。

### QA-202602-12
- 问：可以使用 HWT101 吗？
- 答：不建议，且其内部含 MCU，可能不符合规则。

### QA-202602-13
- 问：场地尺寸调整后，是否保证每队物品种类和数量一致？
- 答：一致，摆放位置也一致，避免不公平。

### QA-202602-14
- 问：辅助车可否进入 `1m x 1m` 物品区？计时从何时开始？辅助车能否先上场？
- 答：可进入但不可触碰物体；计时从搬运车启动开始；辅助车可先上场。

### QA-202602-15
- 问：推杆可以做增摩处理吗？
- 答：可以。

### QA-202602-16
- 问：沙袋只有红蓝两种颜色吗？
- 答：是，仅红色和蓝色。

### QA-202602-17
- 问：泰迪熊购买链接与尺寸要求不一致怎么办？
- 答：自行寻找小型泰迪熊。

### QA-202602-18
- 问：小熊身上有衣服吗？
- 答：无。

### QA-202602-19
- 问：编码器允许自制吗（如 MT6816）？
- 答：允许。

### QA-202602-20
- 问：某搬运车模控制方案是否允许（含 STC 参与）？
- 答：
  - STC32 可用于搬运车模无刷电机控制；
  - STC32F12K54 可用于辅助车模控制；
  - 若搬运车是有刷电机且无 FOC，不允许使用 STC。

### QA-202602-21
- 问：物体出线后滚动碰到辅助车，算犯规吗？
- 答：允许。

### QA-202602-22
- 问：沙包颜色深浅和数字有要求吗？
- 答：仅红/蓝纯色，无数字；蓝色倾向浅蓝。

### QA-202602-23
- 问：辅助车初始位置可以随意放置吗？
- 答：可以。

### QA-202602-24
- 问：辅助车能否一开始就随意进场？
- 答：可以。

### QA-202602-25
- 问：如何保证物体放置位置一致，地面有坐标点吗？
- 答：只有大体区域，没有固定坐标点。

### QA-202602-26
- 问：`TI-INA219` 与 `CEM5881-M11` 是否可用？
- 答：
  - INA219 芯片可用，但现成模块板不允许直接使用；
  - CEM5881-M11 模块可使用。

### QA-202602-27
- 问：可以不用辅助车、也不用导引光标吗？
- 答：可以，二者均为可选项。

## 2. 2026年3月问答

### QA-202603-01
- 问：双车推物时若出现瞬间只有一车接触，是否有效？
- 答：瞬间不同步接触允许；若长期只有一车推动，不符合要求。

### QA-202603-02
- 问：推杆高度有限制吗？
- 答：回复中说明“规则未限定固定高度”，由队伍自行确定合理高度。

### QA-202603-03
- 问：指定摄像模块中存在 C++ 架构，是否允许？
- 答：本组主控模块程序使用 MicroPython 编程。

### QA-202603-04
- 问：可以使用 IMU660RC 吗？
- 答：可以。

### QA-202603-05
- 问：图示模块是否可直接购买并使用？
- 答：可以。

### QA-202603-06
- 问：外形 `<30cm` 是否包含高度？泰迪熊颜色深浅是否有限制？
- 答：
  - 搬运车高度无专门限制；
  - 泰迪熊颜色深浅无特别规定。

### QA-202603-07
- 问：OpenARTPlus 可否焊接排针/转接板（无 MCU）与贴散热片？
- 答：均可以。

## 3. 开发落地澄清（速查）

- 规则主线：双车协同、单件搬运、返回发车区、计时闭环。
- 平台主线：搬运主控 `NXP-MicroPython`，辅助车 `STC`。
- 模块主线：原则上禁用带额外 MCU 的“智能模块”。
- 场地主线：预赛和决赛障碍配置不同，决赛复杂度更高。
- 合规主线：Q&A 可对细则进行解释和补充，工程实现需同步引用。
