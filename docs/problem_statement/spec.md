## 1. 使用方式

- 开发前先阅读「第 5 章 REQ 编号索引」。
- 讨论实现方案时，直接引用 REQ 编号（例如 `REQ-ANT-007`）。
- 若规则与 Q&A 冲突，以最新官方问答澄清为准，并在 `qa.md` 中核对。

## 2. 总则（与本项目相关摘录）

### 2.1 规则导读

- 竞赛分为三类赛道：缩微、室内、室外。
- 缩微赛道允许自制车模；室内/室外组别按指定车模平台或指定配件执行。
- 缩微赛道重量参与成绩计算：超过 `100g` 的部分按“超重克数 / 20”折算秒数叠加到最终成绩。
- 除室外三个组别外，其余组别允许负压；高速风扇需做安全防护；负压风扇驱动与无刷电机 FOC 控制电路可使用 `Infineon`、`STC`、`NXP` 单片机制作。
- 室外组允许使用 GPS，不允许使用 RTK。
- 室内赛道背景为蓝色，赛道白色 PVC，不铺黑色边界线。
- 参赛 PCB 需通过嘉立创指定通道制作，且正面覆铜层需标注学校名、队伍名、制作日期，丝网层需包含制作文件链接二维码；面积小于 `1cm^2` 的小板或纯转接板可不带队伍信息；不合规可判成绩无效。

[![竞赛网站](https://i-blog.csdnimg.cn/direct/f12d439b4ed448658998efec115b6cff.png#pic_center)](http://www.smartcarrace.com/)

### 2.2 版本与冻结时间

- 版本 `0.1`（2025-11-09）：组别、器材、组织方案初稿。
- 版本 `1.0`（2025-12-05）：补充组别细则并公布车模平台信息。
- 规则在 `2026-06-15` 前持续修订，之后冻结。

### 2.3 蚂蚁搬家组在总则中的定位

- 组别：蚂蚁搬家（缩微平面赛道）。
- 任务：自制多车协同，将目标物从场地中央搬运到指定区域。
- 搬运过程要求：
  - 两台或以上车模共同推动。
  - 物体搬运中不得离地。
  - 车模之间不允许物理连接，可无线通信。
- 平台约束：主搬运车模为 `NXP-MicroPython`，辅助车模允许 `STC`。

### 2.4 器材与电子规则（通用）

- MCU 采用组别限定平台；车模内 MCU 数量不限制。
- 允许的图像处理板包含 NXP 体系 OpenART/MV5-RT/MCX Vision（蚂蚁搬家主搬运车可用）。
- 蚂蚁搬家辅助车模不允许使用上述高算力图像处理板（按细则和问答澄清执行）。
- 传感器数量一般不限制，但需满足组别类型限制。
- 除规则明确放行项外，不允许使用带独立微处理器的智能传感器模块。
- 不允许使用标注“智能车比赛专用”的成品传感器模块。

### 2.5 报名、奖项、违规

- 分赛区奖项比例：一等奖前 20%，二等奖 35%，其余按规则分配。
- 同一名队员最多可报名三支队伍。
- 作弊或恶意网络言论造成不良影响，可取消成绩。
- 晋级后每队最多可更换一名队员，指导教师不可变更。

## 3. 蚂蚁搬家组细则（清洗版）

### 3.1 怎么搬

- 参赛队伍制作两辆搬运车模（步兵）。
- 可额外配置不超过 2 台辅助装置（辅助车模/导引信标）。
- 成绩计重仅计算两辆搬运车模平均重量，不计辅助装置。
- 辅助车模高度不超过 `50cm`，且不得触碰搬运物体。
- 计时从搬运车离开发车区开始，到最后一个物体搬运完成结束。
- 中央物品区为 `1m x 1m`，物品按边界到边界计算的最小间距为 `10cm`。
- 每次只允许搬运 1 件物品，不允许单车全程独立搬运。
- 物体越过黄色边界线即算成功，后续因自身滚动回线内不影响成功判定。

![比赛场地示意图](https://i-blog.csdnimg.cn/direct/74b6933015594544be93bae803e7d033.png#pic_center)

#### 推杆约束

- 推杆长度（水平尺寸）不超过 `10cm`。
- 推杆垂直尺寸不超过 `5cm`。
- 推杆必须为直杆，不允许弧度、夹角、针刺、可变形结构。
- 车模整体（含推杆）外形尺寸需小于 `30cm`。

![推杆示意图](https://i-blog.csdnimg.cn/direct/e7ac42ed59734ac3b4f3a32996c267bd.png#pic_center)

![搬运过程示意图](https://i-blog.csdnimg.cn/direct/5fbabb5fd17a48928a4f372f3ebc2c66.gif#pic_center)

### 3.2 搬什么

1. 标准网球（浅绿色），直径 `6.54 ~ 6.86cm`。
2. 玩具沙袋（红色、蓝色），边长 `7cm`。
3. 泰迪熊（棕色、白色），高度小于 `20cm`。

![标准网球](https://i-blog.csdnimg.cn/direct/2a51ad10240d4dfc950aa116bb001f08.png#pic_center)
![玩具沙袋](https://i-blog.csdnimg.cn/direct/ee0ebd69abf7421fad9883602a980e9e.png#pic_center)
![玩具熊](https://i-blog.csdnimg.cn/direct/d7a68009356245a6af7a86e0cf5870c5.png#pic_center)

### 3.3 搬到哪儿

- 预赛：搬出场地即可。
- 决赛：
  - 网球 -> 场地上方
  - 沙袋 -> 场地左方
  - 泰迪熊 -> 场地右方

### 3.4 障碍

- 预赛：无凸起、无砖块障碍。
- 决赛：存在两类障碍：
  1. 路面凸起（可压过），直径约 `25cm`，中心高度约 `1.5cm`。
  2. 砖块路障，可能位于距边界线 `50cm` 范围内。

## 4. 面向开发的 REQ 编号索引

### 4.1 总则类（REQ-GEN）

- `REQ-GEN-001`：本组属于缩微赛道，允许自制车模。
- `REQ-GEN-002`：缩微组重量规则有效，超 `100g` 部分按“克数/20”折算罚时。
- `REQ-GEN-003`：蚂蚁搬家主搬运车模主控采用 `NXP-MicroPython`。
- `REQ-GEN-004`：辅助车模控制平台允许 `STC`，并需满足细则限制。
- `REQ-GEN-005`：除放行项外，不得使用带独立 MCU 的智能传感器模块。
- `REQ-GEN-006`：禁止使用“智能车比赛专用”成品传感器模块。
- `REQ-GEN-007`：PCB 需按官方制作规范标注学校名、队伍名、制作日期，并提供制作文件链接二维码；不合规可判无效成绩。
- `REQ-GEN-008`：同一队员最多参加 3 支队伍。
- `REQ-GEN-009`：作弊或恶意网络言论可取消成绩。
- `REQ-GEN-010`：规则在 `2026-06-15` 前可能修订，开发文档需标记版本时间。

### 4.2 细则类（REQ-ANT）

- `REQ-ANT-001`：必须有两辆搬运车模参与搬运任务。
- `REQ-ANT-002`：辅助装置数量上限为 2。
- `REQ-ANT-003`：计重仅取两辆搬运车模平均重量。
- `REQ-ANT-004`：辅助车模高度不超过 `50cm`。
- `REQ-ANT-005`：辅助车模不得触碰搬运物体。
- `REQ-ANT-006`：场地边界为黄色胶带；边界宽度在最新问答中出现与共用场地统一的调整讨论，需继续跟踪正式正文。
- `REQ-ANT-007`：中心物品区为 `1m x 1m`，物品边界间距至少 `10cm`。
- `REQ-ANT-008`：计时从搬运车离开发车区开始，到最后一个物体搬运完成结束。
- `REQ-ANT-009`：每次只能搬运 1 件物品。
- `REQ-ANT-010`：不允许单车全程独立完成搬运。
- `REQ-ANT-011`：推杆长度不超过 `10cm`。
- `REQ-ANT-012`：推杆垂直尺寸不超过 `5cm`。
- `REQ-ANT-013`：推杆必须为直杆，不允许弧度/夹角/针刺/变形。
- `REQ-ANT-014`：车模整体外形（含推杆）小于 `30cm`。
- `REQ-ANT-015`：物体越过边界线即判成功。
- `REQ-ANT-016`：预赛无障碍，决赛有凸起和砖块障碍。
- `REQ-ANT-017`：决赛定向搬运：网球上、沙袋左、泰迪熊右。
- `REQ-ANT-018`：搬运物体规格需满足网球/沙袋/泰迪熊尺寸与颜色约束。

### 4.3 问答澄清类（REQ-QA）

> 详细条目见 `docs/problem_statement/qa.md`。

- `REQ-QA-001`：辅助车可在边界外运动。
- `REQ-QA-002`：辅助车可先上场，计时从搬运车启动开始。
- `REQ-QA-003`：辅助车可进入物品区，但不得触碰物体。
- `REQ-QA-004`：辅助车不允许使用 OpenART。
- `REQ-QA-005`：可使用 UWB 定位。
- `REQ-QA-006`：无线模块原则上不允许带额外 MCU。
- `REQ-QA-007`：允许碰撞未搬运物体，但不能同时搬运多个物体。
- `REQ-QA-008`：双车瞬间不同步接触可接受，长期单车推动不合规。
- `REQ-QA-009`：沙包仅红/蓝纯色，无数字。
- `REQ-QA-010`：辅助车与导引光标均为可选项。
