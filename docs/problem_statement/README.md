# 题面文档说明

本目录用于存放“第21届智能车竞赛蚂蚁搬家组”题面资料的仓库内 Markdown 版本，目标是让 Agent 在本地稳定读取。

## 阅读顺序

1. `docs/problem_statement/spec.md`
2. `docs/problem_statement/qa.md`
3. `docs/problem_statement/sources.md`

## 使用建议

- 在需求讨论、任务分解、测试设计中，优先引用 `spec.md` 中的 `REQ-*` 编号。
- 遇到规则边界问题，先查 `qa.md`，再回源网页核对。
- 每次官方规则更新后，请同步更新本目录并补充变更记录。

## 维护原则

- 文档语言使用中文。
- 保留规则原意，不做扩展解释。
- 对可能冲突条款，显式标注“需复核”。
