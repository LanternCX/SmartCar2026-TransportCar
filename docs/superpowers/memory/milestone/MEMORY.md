# milestone

## Type
milestone

## Use When
Use this type when you need precedent for completed feature delivery, architecture closure, or workflow-level milestones.

## Avoid When
Avoid this type when you only need debugging root-cause history or maintainability-first structural cleanup examples.

## Record When
Use this type for larger complete changes that form a meaningful feature, architecture adjustment, or workflow closure.

## Avoid Recording When
Do not record debugging-only closures or maintainability-first structural cleanups in this type.

## Entry Template
Use `docs/superpowers/memory/milestone/ENTRY.md`.

## Notes
- Record only closed, reviewable change units.
- Prefer milestone when the main value is new capability, system-level closure, or a meaningful end-to-end improvement.
