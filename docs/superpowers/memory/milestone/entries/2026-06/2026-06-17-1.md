## Title
收口 YOLO 慢帧前后本地视觉可靠暂停控制

## Background / Issue
OpenART 物体 YOLO 帧耗时明显高于普通帧, 慢帧期间继续沿用上一轮速度会影响底盘控制稳定性。速度流本身仍需要保持 UDP 最新值语义, 慢帧前后的上下文建立适合放入低频可靠同步链路。

## Change Unit
主仓库和视觉仓库共同完成 `LOCAL_VISION_CONTROL` 可靠控制闭环: OpenART 在 YOLO 慢帧前请求车端暂停, 暂停确认后运行 YOLO, YOLO 帧不输出速度和事件, 帧后请求恢复; 车端收到暂停后写零速度, 恢复后丢弃恢复前缓存速度, 只接收新的 UDP 速度。

## Actions / Outcome
- 新增 `LOCAL_VISION_CONTROL` 可靠 topic 与编解码 -> 低频暂停/恢复控制进入正式协议表。
- 主车和辅车运行时消费暂停/恢复可靠包 -> 暂停期间保持零速度, 恢复时清理旧速度缓存。
- 主辅 OpenART `main_v2` 在 YOLO 帧前后发送暂停/恢复请求 -> YOLO 慢帧不再承担真实控制输出。
- 同步行为测试和开发文档 -> 主仓与视觉仓全量测试覆盖协议、运行时和入口循环行为。

## Lessons / Refinements
- 高频速度继续使用 UDP 最新值语义, 只把低频上下文控制放入可靠同步链路。
- 慢帧保护应优先收口在视觉入口与车端本地视觉 owner 之间, 不把 YOLO 内部状态扩展到底盘协议。
- 恢复控制时清理恢复前缓存速度, 避免慢帧期间积压的旧 UDP 在恢复后立即生效。
