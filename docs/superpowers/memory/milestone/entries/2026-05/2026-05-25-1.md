## Title
接入主辅绕行阶段视觉平移修正

## Background / Issue
绕行阶段受地面摩擦、轮胎打滑和速度环偏软影响, 绕行半径会产生漂移。主车和辅车都需要在统一绕行基准运动上叠加目标物体视觉 `X/Y` 平移修正, 让绕行更稳定地围绕目标物体。

## Change Unit
该变更同时收口 OpenART 视觉仓库和车端运行时: 视觉侧新增主车与辅车绕行修正模式, 车端共享底盘新增绕行平移修正入口, 主车与辅车角色运行时在绕行阶段读取本车 `UART6` 视觉速度并叠加到统一绕行基准运动。

## Actions / Outcome
- OpenART 主车与辅车视觉入口新增绕行修正模式 -> 绕行阶段继续识别红色目标并输出 `v,<vx>,<vy>`。
- `TransportCar` 新增绕行平移修正入口 -> 视觉修正只影响平移轴, 不改变角速度链路、半径倍率和命令锁完成判据。
- 主车 `ORBITING` 与辅车 `ASSISTANT_ORBIT` 接入本车 `UART6` 修正 -> 两台车绕行时都能使用目标物体视觉修正半径漂移。
- 主车绕行视觉同步使用独立可靠序号 -> 绕行 ACK 不会误确认绕行后的主流程 hook。

## Lessons / Refinements
- 绕行修正应作为平移速度叠加处理, 不把视觉误差重新解释成半径模型。
- 绕行修正参数应独立于搜索、找物体和跟随参数, 便于实车分别调参。
- 绕行阶段的视觉同步不应推进主流程 hook 序号, 但也不能复用后续 hook 的可靠序号。

## Integration Summary
该改动形成一个独立可审查的绕行稳定性提升单元。视觉侧负责持续输出目标物体平移修正, 车端角色层负责阶段同步和输入编排, 共享底盘负责把修正量叠加到统一绕行运动中。
