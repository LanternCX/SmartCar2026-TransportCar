## Title
收口主车回库为黄线采样停车

## Background / Issue
现场确认回库不需要依赖色标对正。主车回库平移时, 长边线会让中线采样上下界均值产生不符合跟随语义的黄线 Y, 需要在不引入窗口滤波和跳变计数的前提下完成停车判定。

## Change Unit
主车回库主线收敛为后退对正黄线、黄线平移入库、Y=160 有黄色且 X=270 连续 5 帧无黄色完成停车。车端取消回库色标状态入口, OpenART 主车视觉取消回库色标 hook 主流程, 黄线平移阶段使用原始黄线 Y 输出纵向速度, 并在 Y=160 有黄色且 X=270 连续 5 帧没有黄色时回报完成事件。

## Actions / Outcome
- 车端主车状态机取消回库色标跳转 -> `RETURN_GARAGE_LINE` 收到回库完成事件后直接进入完成态。
- 车端主车运行时取消回库色标 hook 和色标速度消费 -> 回库平移只组合固定左移和黄线纵向速度。
- OpenART 主车回库黄线速度恢复直接使用原始 Y -> 回库纵向控制保持黄线跟随语义。
- OpenART 主车回库黄线平移在 Y=160 有黄色且 X=270 连续 5 帧没有黄色时回报完成事件 -> 主车完成停车并同步辅车停止。
- Spec、Plan 和视觉职责文档同步 -> 本轮设计与实现边界保持一致。

## Lessons / Refinements
- 回库黄线阶段的停车判定优先使用固定列采样的可观测特征, 不通过窗口或跳变次数扩展状态。
- 取消状态时同时清理车端状态机、运行时入口、OpenART hook 分发和契约测试, 避免留下可触发的旁路。
- 倒装矫正后的 Y 语义必须先统一再讨论控制方向, 不按平移方向假设目标值单调变化。
