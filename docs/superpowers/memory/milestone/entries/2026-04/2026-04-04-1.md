## Title
完成主车底盘控制重构阶段的姿态、方向与节拍闭环调试

## Background / Issue
本轮主车底盘控制重构的目标不是简单回退 legacy 文件, 而是在当前轻量主线骨架内, 把影响稳定性的核心控制语义重新收回来并调通。联调过程中先后暴露出姿态观察口径不一致、轮子方向与已验证脚本不一致、以及高频打印会拖坏控制周期这三类问题, 直到全部闭环后, 用户确认本次重构范围内的底盘控制部分已经调试通过, 需要以 milestone 形式沉淀。

## Change Unit
完成主车底盘控制重构阶段的关键闭环: 补齐航向保持语义, 让运行时姿态链对齐已验证的 `inspect_attitude` 口径, 修正主车运行时电机/编码器映射到已验证脚本基线, 并把角度环、速度环、前馈统一切到同拍动态 `dt`, 使主车底盘控制在当前阶段达到可验证、可继续收口的稳定状态。

## Actions / Outcome
- 回收主车航向保持关键语义 -> 主动转动与自动保持的切换、重新接管当前朝向、角速度阻尼项都恢复到更接近 legacy 的稳定行为。
- 对齐姿态观察口径 -> 运行时姿态更新改为跟 `src/master/test/inspect_attitude.py` / `src/master/script/inspect_attitude.py` 同一套 `yaw_deg` 口径, 大角度手动旋转时的量级恢复正常。
- 修正运行时硬件映射 -> 主车正常运行时的电机端口与编码器映射改成和已验证的 legacy 风格脚本一致, 现场轮子方向不再受映射冲突影响。
- 统一全链路动态节拍 -> 角度环积分、三个速度环积分与前馈变化率共用同拍真实 `dt`, 大量日志打印导致周期拉长时不再把前后控制环算成两套时间基准。
- 补齐主机侧回归与 HIL 留证骨架 -> 相关主车单测持续通过, 同时把 Stage 2 / Stage 3 留证模板拆开, 为后续板端验收保留清晰入口。

## Lessons / Refinements
- 对主车底盘控制这种硬件强相关重构, “口径一致”比单点参数一致更重要: 姿态观察口径、接线映射和节拍基准只要有一项不一致, 现场手感就会明显偏离。
- 当联调现象会随着打印量变化而变化时, 应优先怀疑时间基准不一致, 不要先把问题误判成纯参数软硬。
