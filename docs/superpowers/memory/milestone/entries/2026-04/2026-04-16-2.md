## Title
切换主辅正式通信链路到 UART8

## Background / Issue
当前仓库刚把主辅双侧角色运行时收口到统一协同链路，但正式口径、运行时代码和测试都把主辅通信固定在 `UART3`。现场已经确认本轮正式接线改为 `UART8`，若继续保留旧口径，会让主车转发、辅车接收、查询回包和联调文档长期按错链路理解。

## Change Unit
把当前阶段主辅正式通信链路整体从 `UART3` 切到 `UART8`，同步收口共享底盘串口入口、主车转发运行时、辅车跟随运行时、查询回包口、主机侧测试以及开发文档和规则入口，使代码、规则和联调口径重新保持一致。

## Actions / Outcome
- 把共享底盘正式通信串口改为 `UART8`，并同步调整主车转发与辅车接管运行时 -> 主辅协同控制和查询回包都走同一条 `UART8` 链路
- 保持辅车 `UART6` 本地视觉输入边界不变，只替换主辅通信口 -> 跟随闭环结构不扩面，只改正式通信接线口径
- 补齐单元测试、契约测试、开发文档和规则入口 -> 代码事实、测试验证和联调说明重新对齐到 `UART8`

## Lessons / Refinements
- 涉及串口职责切换的改动，必须同时维护运行时代码、测试、开发文档和规则入口，否则后续联调会继续按旧链路排查
- 当现场接线已经确认迁移到新串口时，应直接把正式口径一起切过去，不要保留“代码实际走新口、文档仍写旧口”的半迁移状态
