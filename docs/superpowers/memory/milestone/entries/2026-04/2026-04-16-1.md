## Title
完成主车与辅车双侧角色运行时开发闭环

## Background / Issue
双车协同当前阶段需要把主辅两侧角色职责同时落地。辅车侧需要稳定接管 `UART3` 速度控制与 `UART6` 本地视觉输入，形成最小跟随闭环；主车侧需要把 `UART3` 下行控制中的速度字段稳定转发给辅车，同时保留主车本地底盘并行执行能力。

## Change Unit
先为辅车落地本地视觉闭环与速度融合角色运行时，再为主车补齐 `UART3` 单链路速度转发角色运行时；同步更新角色分发表测试、运行时测试以及控制与视觉开发文档，使主辅双侧角色入口、串口职责和当前阶段边界保持一致。

## Actions / Outcome
- 为辅车新增角色运行时并接管 `UART3` 与 `UART6` 输入编排 -> 辅车侧形成可落地的本地视觉闭环与速度融合执行链
- 为主车新增专用角色运行时并替换角色入口返回对象 -> 主车角色层可以在本地执行底盘命令的同时，经 `UART3` 上行转发 `vx/vy/omega/w` 速度字段
- 补齐双侧运行时测试、角色工厂测试以及开发文档 -> 主辅职责、串口语义与目录口径统一收口

## Lessons / Refinements
- 当主辅两侧阶段性职责已经清晰分离时，应优先把行为收口在各自角色运行时，而不是继续把角色逻辑塞回共享底盘
- 涉及串口职责切换或角色边界变更的改动，应同步维护开发文档、测试与协作文档，否则后续联调容易按旧职责理解入口边界
