## Title

## Background / Issue
`docs/mpy-cli.md` 已新增 `list` 命令、扫描策略，以及 `device_upload_dir`、`.mpyignore`、`run/delete/tree` 的路径语义，但 `.agents/skills/mpy-cli/SKILL.md` 仍停留在旧版本，无法完整指导 agent 处理“串口未知时先发现设备再部署”的场景。

## Change Unit
补齐 mpy-cli skill 对串口发现、上传路径边界和运维命令语义的指导，收口 agent 默认操作顺序。

## Actions / Outcome
- Approach 1: 先做场景基线验证 -> 确认旧 skill 会把 agent 引向 `init/config -> plan/deploy`，但会遗漏 `mpy-cli list`
- Approach 2: 评估全文重写 -> 可读性会更统一，但改动面偏大，不符合本次“补齐现有能力”的目标
- Final approach: 保留既有章节结构，最小化补齐 `list`、扫描策略、`.mpyignore` / `device_upload_dir` / `run/delete/tree` 语义与 `delete` 递归删除风险 -> skill 已与当前 docs 的关键决策点对齐

## Lessons / Refinements
- 面向 agent 的 skill 需要优先补“决策入口”和“风险边界”，不必复制完整命令手册
- 当底层工具新增端口发现能力时，skill 必须同步把“未知端口先发现设备”提升为默认操作顺序
