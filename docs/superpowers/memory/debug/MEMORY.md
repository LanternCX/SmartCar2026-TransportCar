# debug

## Type
debug

## Use When
Use this type when you need precedent about observed symptoms, confirmed root causes, fixes, and verification evidence.

## Avoid When
Avoid this type when you are looking for feature-delivery history or structural refactor examples.

## Record When
Use this type for complete debugging closures where the problem is identified, fixed, and verified.

## Avoid Recording When
Do not record new feature delivery or broad structural cleanup whose main value is maintainability in this type.

## Entry Template
Use `docs/superpowers/memory/debug/ENTRY.md`.

## Notes
- Record only closed debugging loops, not ongoing investigation.
- Prefer debug when the main value is preserving the failure mode, root cause, fix, and verification outcome.
