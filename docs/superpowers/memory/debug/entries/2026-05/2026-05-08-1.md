## Title
修复状态跳转沿用未完成目标角度导致的航向保持错误

## Background / Issue
主车和辅车在连续状态跳转中会先执行位置式角度控制, 随后进入下一个动作阶段。调试中发现部分状态会在上一个目标角度尚未完全转到位时直接进入下一状态, 后续阶段继续沿用这个未完成的目标角度, 导致理论目标角度和实际保持角度逐步偏离, 最终表现为整个协同搬运过程中的车身目标角度保持错误。

## Change Unit
将位置式目标角度从“一次性跳转时写入”收口为“后续阶段持续保持理论目标角度”的控制语义。状态跳转后, 车体不再把上一阶段未完成的错误目标当作新阶段的保持目标, 而是在位置式控制目标角度确定后, 通过后续自身位置保持持续对正到理论目标角度。

## Actions / Outcome
- 复核状态跳转与目标角度继承关系 -> 确认故障源不是单个状态编号错误, 而是未完成目标角度被后续状态继续沿用。
- 修正位置式角度控制后的保持语义 -> 后续阶段持续向理论目标角度对正, 而不是保持中间过渡角度。
- 补充绕行后和位置式角度相关回归 -> 固定状态跳转后目标角度不漂移的边界。
- 调整主动转向与保持阶段的角速度限制 -> 主动转向可以慢速收敛, 保持阶段继续维持稳定航向。

## Lessons / Refinements
- 状态机切换不能默认“上一阶段目标角度已经执行完成”, 只要允许提前进入下一阶段, 就必须明确下一阶段的理论保持角度。
- 位置式角度目标要区分过渡目标和保持目标；保持阶段应持续对正到理论目标角度, 不能继承未完成的中间目标。
- 多阶段协同动作调试时, 航向错误常常不是当前阶段第一次写错, 而是前一阶段未完成目标在状态切换后被继续使用。
