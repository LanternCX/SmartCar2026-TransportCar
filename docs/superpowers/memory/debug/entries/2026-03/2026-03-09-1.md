## Title
将视觉对正从单点观测切换为完整识别框

## Background / Issue
当前视觉链路只向主控回传 `x,y`，状态机也直接把 `x/y` 当成横向与纵向对正依据。这无法表达识别框底边信息，导致“目标框底边应与画面底边对齐”的真实判据无法落地，也让状态跳转缺少完整观测上下文。

## Change Unit
修复视觉对正仍使用单点观测的问题，将状态机输入切换为完整识别框语义。

## Actions / Outcome
- Approach 1: 继续沿用 `x,y` 并补少量派生量 -> 无法可靠恢复底边语义，且状态跳转信息仍不完整
- Approach 2: 兼容 `x,y` 与完整框双协议并在状态机内部分流 -> 兼容性更强，但输入语义分裂，容易继续保留旧歧义
- Final approach: 将视觉协议切换为 `left,top,right,bottom` 完整框，协议层吞掉 `UART6` 上的旧 `x,y` / 不完整视觉载荷，状态机改为使用 `center_x` 与 `bottom` 判据，`?vision` / 文档 / HIL 场景同步升级 -> 主机侧 `149` 项测试通过，Stage 2 smoke 在 `/dev/cu.usbmodem11301` 返回 `status=ok reason=ok`

## Lessons / Refinements
- 当视觉状态机会基于“框边界关系”做阶段切换时，协议层必须直接回传完整框，不能再把单点观测硬塞给状态机
- `UART6` 同时承载视觉与命令时，旧视觉字段必须优先被协议层吞掉，否则很容易误落入手动命令链
