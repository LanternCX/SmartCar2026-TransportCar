# 2026-04-22 平移转向命令解耦与融合设计

> 执行状态：Archive

## 背景

当前共享底盘的控制执行链本身已经支持“平移量 + 转向量”在同一控制拍内融合，再统一分配到三轮目标速度。因此，车体从控制算法角度具备边平移边旋转的能力。

这轮暴露的问题不在执行层，而在命令收口层：

1. 任意速度包都会把 `x/y/angle` 一起清掉，导致跨轴目标被误删。
2. 辅车角色层把 `angle` 透传后，会因为后续速度写回再次把角度目标冲掉。
3. 主车把上游 `omega` 替换成给辅车的 `angle` 时，当前实现把“是否带角度”扩大成了“任意速度包都附带角度”，范围过大。

本轮目标是把命令冲突规则改成“同轴互斥、跨轴共存、执行阶段统一融合”。

## 目标

1. 让平移控制与转向控制在命令语义上解耦。
2. 让共享底盘继续在单拍内把平移与转向统一融合到三轮速度。
3. 让辅车能够正确执行 `vx/vy + angle` 组合命令。
4. 让主车只在上游包显式带 `omega/w` 时，才派生并转发当前绝对角度 `angle`。
5. 保持当前协议短键值格式，不新增第二套控制协议。

## 非目标

1. 不重写三轮运动学。
2. 不拆成两套执行内核。
3. 不把 `lock` 细分成平移锁和转向锁两套独立状态。
4. 不在本轮引入新的串口链路或超时语义。

## 设计决策

### 决策一：命令冲突按平移轴和转向轴分组

平移轴字段：

1. 位置式：`x/y/dx/dy`
2. 速度式：`vx/vy`

转向轴字段：

1. 位置式：`angle/yaw/d_angle`
2. 速度式：`omega/w`

冲突规则固定为：

1. 平移速度式只清理平移位置式目标。
2. 平移位置式只接管平移轴，不清理转向轴目标。
3. 转向速度式只清理转向位置式目标。
4. 转向位置式只接管转向轴，不清理平移轴目标。

因此：

1. `vx/vy + angle` 合法，并应边走边转。
2. `x/y + omega` 合法，并应在走位置时允许显式转向接管。
3. `vx=0,vy=0,angle=目标角` 合法，并应表现为原地转到目标角。

### 决策二：同轴同包混发时，速度式优先

若同一条命令行里同时出现同一轴的位置式和速度式字段，则按速度式收口：

1. `x/y` 与 `vx/vy` 同包时，最终以 `vx/vy` 为准。
2. `angle/d_angle` 与 `omega/w` 同包时，最终以 `omega/w` 为准。

这样可以保持“显式速度接管位置目标”的统一口径，也与当前底盘直接速度命令的优先级一致。

### 决策三：融合发生在共享底盘控制拍，不上提到角色层轮速相加

本轮不在主车或辅车角色层直接计算三轮速度并相加。统一口径保持为：

1. 平移目标先在共享底盘中生成当前拍平移量。
2. 转向目标先在共享底盘中生成当前拍转向量。
3. 两者在共享底盘控制拍末端统一融合，再进入三轮逆运动学和速度环。

这样可以继续复用现有底盘的限幅、闭环和模式边界，不引入双重融合来源。

### 决策四：主车只在收到 `omega/w` 时转发当前绝对角度

主车到辅车的转发规则固定为：

1. `vx/vy` 继续原样转发。
2. 若上游包里出现 `omega/w`，主车不直接透传该角速度，而是用主车当前 `heading_est` 派生 `angle` 字段转发给辅车。
3. 若上游包里没有 `omega/w`，主车不额外补发 `angle`。

因此，主车转发链只做“角速度到当前绝对角度”的替换，不扩大成“任意速度包都附带角度”。

### 决策五：辅车速度写回在没有显式角速度输入时不再补写 `omega=0`

辅车角色层在组装最终速度写回时，需要区分“显式给了角速度 0”和“当前包根本没有角速度字段”：

1. 若当前有效输入显式带了 `omega/w`，则继续把该值写回共享底盘。
2. 若当前有效输入没有显式角速度字段，则角色层只写回 `vx/vy`，不额外补 `omega=0`。

这样可以避免角色层在 `vx/vy + angle` 场景下，把刚透传进来的角度目标又当拍清掉。

### 决策六：辅车透传保护只保平移位置目标，不再把角度目标当成整包阻塞条件

辅车角色层当前的透传保护语义要收窄：

1. `x/y/dx/dy` 透传后，仍要阻止后续速度写回立即把平移位置目标冲掉。
2. `angle/yaw/d_angle` 单独透传后，不再阻止 `vx/vy` 写回。

这样角度目标可以和线速度长期共存，并在共享底盘里统一融合执行。

## 验证口径

本轮完成后，至少要能稳定满足以下行为：

1. `angle=45,lock=1` 之后再发 `vx=12`，角度目标仍保留，平移速度生效。
2. `x=1.0,lock=1` 之后再发 `vx=12`，平移位置目标被速度接管。
3. `angle=45,lock=1` 之后再发 `omega=12`，角度目标被角速度接管。
4. 辅车收到 `vx=1.0,angle=45.0` 后，同拍即可保留角度目标并生效平移速度。
5. 主车收到 `vx=1.0,omega=0.5` 时，转发给辅车的是 `vx=1.0,angle=<heading_est>`；收到纯 `vx=1.0` 时，不额外附带 `angle`。
