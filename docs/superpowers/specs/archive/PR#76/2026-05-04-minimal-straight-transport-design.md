# 最小直行搬运态设计

> 执行状态: Archive
>
> 归档条件: 对应实现完成并通过验证后, 将本文件标记为 Archive。

## 目标

实现最小直行搬运态。两台车都完成物体侧面切入和二次对正后, 主车进入搬运态并主导推进, 辅车进入搬运子状态并辅助倒退。搬运方向为主车车体系正前方, 基础速度使用 `TRANSPORT_FORWARD_SPEED`。两台车在搬运过程中各自继续使用本车视觉速度修正物体相对位置。

当前已经实现的寻找与就位状态机必须完整跑到底。本设计只在既有末端之后追加搬运态, 不改变前半段顺序、触发条件和中间行为。

## 范围

本设计覆盖:

- 两车就位后的搬运态进入条件。
- 既有寻找、绕行、辅车找物体和辅车绕行流程完成后的追加状态。
- 主车搬运态的基础速度和本车视觉修正融合。
- 主车通过 `UART8` 向辅车发送搬运前馈。
- 辅车搬运子状态的前馈方向换算和本车视觉修正融合。
- OpenART 主车和辅车视觉入口按搬运入口语义回报 `ALIGNED`。
- 搬运态相关状态、事件、参数和文档同步。

本设计不覆盖:

- 避障插入。
- 边界检测和越线停止。
- 多目标循环收尾。
- 横向协同搬运构型。
- 新增硬件链路或引脚定义。
- 视觉仓库内的图像识别算法重写。

## 前置事实

- 主车维护全局状态机, 辅车子状态由主车通过 `UART8` 同步。
- 主车本车视觉链路使用 `UART6`, 辅车本车视觉链路使用辅车 `UART6`。
- `UART8` 承载主辅速度前馈、辅车状态同步和辅车结果回报。
- 速度包使用 `v,<vx>,<vy>[,<omega>]`, 其中 `vx / vy` 是车体系速度。
- 项目控制文档中 `x` 轴表示横向, `y` 轴表示纵向。
- 直行搬运的基础推进速度使用主车车体系正 `y` 方向。
- OpenART 视觉仓库位于 `../SmartCar2026-Vision`, 协作规格和计划仍在本仓库维护。

## 状态与事件设计

### 主车全局状态

增加主车搬运状态:

- `TRANSPORT_OBJECT`: 主车主导直行搬运, 本车底盘执行基础推进速度与本车视觉修正的融合结果, 并通过 `UART8` 发送当前底盘速度给辅车。

主车状态流: `IDLE -> SEARCH_OBJECT -> ORBITING -> SEARCH_OBJECT -> TRANSPORT_OBJECT`。

第二次进入 `SEARCH_OBJECT` 后, 该状态表示主车持续对正目标物体。主车在该阶段继续使用本车 `UART6` 视觉速度。主车收到本车视觉 `ALIGNED` 事件后记录本车就位, 但只有同时收到辅车就位回报后才进入 `TRANSPORT_OBJECT`。

`TRANSPORT_OBJECT` 只能在既有前半段完成后追加进入。主车找到物体、等待辅车 idle、主车绕行、辅车找物体、辅车绕行和绕行后二次对正这些步骤保持既有顺序。

### 辅车子状态

增加辅车搬运子状态:

- `ASSISTANT_TRANSPORT_OBJECT`: 辅车辅助搬运, 消费 `UART8` 搬运前馈和本车 `UART6` 视觉修正, 经过头对头方向换算后写入共享底盘。

辅车状态流: `ASSISTANT_FOLLOW -> ASSISTANT_IDLE -> ASSISTANT_APPROACH_OBJECT -> ASSISTANT_ORBIT -> ASSISTANT_APPROACH_OBJECT -> ASSISTANT_TRANSPORT_OBJECT`。

辅车在 `ASSISTANT_ORBIT` 完成后回到 `ASSISTANT_APPROACH_OBJECT` 的本地对正语义。辅车本地视觉回报 `ALIGNED` 后, 辅车通过 `UART8` 向主车回报就位。主车收到该回报并确认本车也就位后, 向辅车同步 `ASSISTANT_TRANSPORT_OBJECT`。

`ASSISTANT_TRANSPORT_OBJECT` 只能由主车在辅车既有子状态链路完成后同步下发。辅车不得在找物体、绕行或绕行后对正尚未完成时自行进入搬运子状态。

### 事件

沿用状态文档中的 `ALIGNED` 事件编号。语义如下:

- 主车本车 `UART6` 的 `ALIGNED`: 主车侧物体二次对正完成。
- 辅车 `UART8` 回报的 `ALIGNED`: 辅车侧物体二次对正完成。
- `TARGET_FOUND`: 保持寻找和绕行前的目标发现语义, 不作为搬运态进入条件。

OpenART 主车视觉需要支持搬运入口 hook 配置。该配置继续输出 `v,<vx>,<vy>` 物体相对位置修正, 稳定进入目标窗口后回报 `ALIGNED`。

OpenART 辅车视觉需要支持搬运入口配置。该配置复用找物体速度输出语义, 稳定进入目标窗口后回报 `ALIGNED`。初次找物体配置继续回报 `TARGET_FOUND`。

## 速度融合设计

### 主车搬运速度

主车搬运态每拍写入:

- 基础速度: `vx = 0`, `vy = TRANSPORT_FORWARD_SPEED`, `omega = 0`。
- 本车视觉修正: 来自主车 `UART6` 最近一条合法 `v,<vx>,<vy>`。
- 最终平移速度: 基础速度与本车视觉修正按轴相加。
- 旋转速度: 搬运态不从视觉取 `omega`, 依赖底盘本地方向保持。

主车继续按当前写入共享底盘的速度目标经 `UART8` 发送前馈。辅车接收的前馈来源就是主车搬运态最终底盘速度, 而不是固定速度常量本身。

### 辅车搬运速度

辅车搬运态每拍融合:

- `UART8` 前馈: 主车当前底盘速度。
- `UART6` 视觉修正: 辅车本车视觉输出的物体相对位置修正。

两车在搬运态为头对头结构。辅车对 `UART8` 前馈先做车体系换算:

前馈换算关系: `assistant_feedforward_vx = -master_forward_vx`, `assistant_feedforward_vy = -master_forward_vy`。

换算含义:

- `x` 方向镜像。
- `y` 方向做前后符号转换。

辅车最终平移速度: `vx = assistant_feedforward_vx + assistant_vision_vx`, `vy = assistant_feedforward_vy + assistant_vision_vy`。

辅车搬运态的前馈融合链路与 `ASSISTANT_FOLLOW` 保持同一类输入语义:

- `UART8` 前馈和 `UART6` 视觉修正同时存在时按轴融合。
- 只有 `UART8` 前馈存在时, 辅车按换算后的前馈运动。
- 只有 `UART6` 视觉修正存在时, 辅车按本车视觉修正运动。
- 任一路缺失不阻塞另一条输入生效。
- 两路都没有合法输入时, 辅车不主动生成搬运速度。

辅车搬运态不使用 `UART8` 的 `omega` 作为搬运旋转前馈, 旋转保持交给底盘本地方向保持。

## 参数设计

参数集中放入 `src/config/params.py`:

- `TRANSPORT_FORWARD_SPEED`: 最小直行搬运基础速度, 参数值为 `5.0`。
- `MASTER_TRANSPORT_HOOK_CONFIG_ID`: 主车搬运视觉配置编号。
- `ASSISTANT_TRANSPORT_OBJECT_CONFIG_ID`: 辅车搬运视觉配置编号。

如果视觉侧直接复用找物体配置, 对应配置编号可以先与找物体配置保持一致。参数仍独立命名, 方便后续联调时分别调整。

视觉仓库中同步维护同名配置编号。视觉侧不改变图像识别算法, 只根据配置编号区分回报 `TARGET_FOUND` 还是 `ALIGNED`。

## 串口与协议设计

不新增串口链路, 不新增包类型。

需要补充状态编号和状态语义:

- 主车 `TRANSPORT_OBJECT`。
- 辅车 `ASSISTANT_TRANSPORT_OBJECT`。

需要补充 `ALIGNED` 在搬运入口中的语义:

- 主车本地视觉通过主车 `UART6` 回报。
- 辅车本地视觉通过辅车 `UART6` 回报后, 辅车再通过 `UART8` 回报给主车。

搬运速度仍使用 `v` 数据流短包。可靠就位事件仍使用 `r` 包。辅车搬运状态同步仍使用 `s` 包。

## 错误处理与边界

- 主车未收到本车 `ALIGNED` 或辅车 `ALIGNED` 时, 保持二次对正状态。
- 辅车未收到搬运子状态同步时, 保持二次对正状态。
- 既有前半段状态未跑完时, 搬运态入口不生效。
- 搬运态内非法速度包不覆盖上一条合法速度。
- 显式零包只清空对应来源的速度贡献。
- 辅车搬运态中任一输入来源缺失时, 另一输入来源仍可单独驱动底盘。
- `ASSISTANT_IDLE` 与 `ASSISTANT_ORBIT` 继续忽略速度输入。
- 搬运态不引入超时停车逻辑。
- 搬运态不引入避障、边界停止或收尾状态。

## 测试要求

主机侧测试覆盖:

- 主车状态机在本车和辅车都 `ALIGNED` 后进入搬运态。
- 主车状态机在前半段未完成时忽略本车或辅车 `ALIGNED`。
- 主车只收到单侧 `ALIGNED` 时不进入搬运态。
- 主车搬运态写入基础速度与本车视觉修正的融合结果。
- 主车搬运态通过 `UART8` 转发融合后的底盘速度。
- 辅车状态机接受搬运子状态。
- 辅车搬运态对 `UART8` 前馈做 `x/y` 双轴符号换算。
- 辅车搬运态叠加本车 `UART6` 视觉修正。
- 辅车搬运态缺少 `UART8` 或 `UART6` 任一路时, 另一条输入仍能单独生效。
- OpenART 主车搬运入口配置在稳定对正后回报 `ALIGNED`, 并持续输出视觉速度。
- OpenART 辅车搬运入口配置在稳定对正后回报 `ALIGNED`, 初次找物体配置继续回报 `TARGET_FOUND`。
- 辅车绕行后对正完成只回报 `ALIGNED`, 不重复触发绕行。
- 既有寻找、绕行、跟随、idle 行为保持通过。
