# 主车回库固定列采样停车设计

> 执行状态: Archive
> 日期: 2026-05-31

## 目标

主车回库黄线平移阶段使用固定采样行和固定采样列的黄色分布作为停车判据。黄线纵向速度直接使用原始黄线 Y, 不做目标值下界限制。

## 范围

本设计只覆盖主车 OpenART 回库黄线平移阶段的停车判定和黄线速度输入。车端状态机、可靠事件链路、辅车完成同步和回库色标取消口径保持不变。

## 算法

1. 回库后退段继续使用黄线 Y 越过目标值触发对正事件。
2. 回库黄线平移段继续根据原始黄线 Y 输出纵向速度。
3. 回库黄线平移段额外采样 Y=160 图像行和 X=270 图像列。
4. Y=160 行存在黄色且 X=270 列连续 5 帧没有任何黄色像素时, OpenART 回报回库完成事件。
5. Y=160 行没有黄色或 X=270 列存在黄色时, 不回报完成事件并重新累计。

## 测试边界

- 原始黄线 Y 小于目标 Y 时, 纵向速度按原始误差输出。
- 回库黄线平移段丢线不回报完成事件。
- 回库黄线平移段 Y=160 有黄色且 X=270 连续 5 帧没有黄色后回报完成事件。
- 回库黄线平移段 Y=160 没有黄色时不回报完成事件。

## 完成判据

- 主车回库平移停车只依赖 Y=160 行有黄色且 X=270 列连续 5 帧没有黄色。
- 主车和视觉仓库相关测试通过。
