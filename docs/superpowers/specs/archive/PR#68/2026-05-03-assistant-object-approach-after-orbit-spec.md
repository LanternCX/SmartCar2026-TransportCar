# 主车绕行后辅车找同目标 Spec

> 执行状态: Archive  
> 创建日期: 2026-05-03  
> 范围: 主车绕行完成后的辅车前进找物体闭环

## 目标

主车在 `ORBITING` 绕行完成后, 通过主辅通信通知辅车进入找物体阶段。辅车停止跟随主车橙色色标, 切换为识别与主车相同的红色目标物体, 依据辅车视觉输出向目标前进。辅车视觉确认目标稳定进入目标窗口后, 辅车停止运动并把“目标已找到”结果可靠回报给主车。

## 范围

### 包含

- 主车绕行完成后生成一次辅车找物体同步请求。
- 主车通过主车侧 `UART8` 包边界向辅车可靠同步新的辅车子状态。
- 辅车新增 `ASSISTANT_APPROACH_OBJECT` 子状态。
- 辅车新增 `ASSISTANT_TARGET_OBJECT` 目标编号。
- 辅车 RT1021 收到找物体子状态后, 通过本车 `UART6` 向辅车 OpenART 同步视觉任务。
- 辅车 OpenART 在找物体视觉任务中识别红色目标物体, 输出 `v,<vx>,<vy>`。
- 辅车 RT1021 在找物体子状态中使用辅车 OpenART 的速度作为前进与对准输入。
- 辅车 OpenART 稳定找到目标后, 通过可靠事件回报 `TARGET_FOUND`。
- 辅车 RT1021 收到本地视觉 `TARGET_FOUND` 后停止辅车线速度, 并通过 `UART8` 将结果可靠回报给主车。
- 主车接收并记录辅车找物体结果。
- 使用主仓库与视觉仓库的主机侧测试固定协议和状态行为。

## 状态设计

### 主车全局状态

主车全局状态编号保持当前 `IDLE -> SEARCH_OBJECT -> ORBITING -> IDLE` 主线。`ORBITING` 完成后, 主车回到 `IDLE`, 同时产生一次辅车找物体同步请求。该请求不新增主车正式状态编号。

主车在等待辅车找物体同步 ACK 时, 不阻塞底盘周期, 只维持可靠同步重发。ACK 只表示辅车已处理同步包, 不表示辅车已经找到物体。

### 辅车子状态

辅车子状态新增一项:

| 编号 | 名称 | 含义 |
| --- | --- | --- |
| `0` | `ASSISTANT_IDLE` | 辅车停止线速度, 忽略速度输入 |
| `1` | `ASSISTANT_FOLLOW` | 辅车融合主车前馈和本车视觉修正, 跟随主车标记 |
| `2` | `ASSISTANT_APPROACH_OBJECT` | 辅车识别并靠近目标物体 |

辅车子目标新增一项:

| 编号 | 名称 | 含义 |
| --- | --- | --- |
| `0` | `ASSISTANT_TARGET_NONE` | 无辅车子目标 |
| `1` | `ASSISTANT_TARGET_OBJECT` | 与主车相同的搬运目标物体 |

`ASSISTANT_APPROACH_OBJECT` 使用 `ASSISTANT_TARGET_OBJECT`。`arg` 表示辅车找物体视觉配置编号, 本轮使用 `1`。

## 通信设计

### UART8 职责边界

`UART8` 主辅链路不继续使用共享层 `src/protocol/uart8_packet.py` 作为共同业务入口。主车和辅车分别维护自己的 `UART8` 包边界:

- 主车侧只维护主车需要发送和接收的 `UART8` 字段: 发送辅车子状态同步, 接收 ACK, 接收辅车结果回报。
- 辅车侧只维护辅车需要接收和发送的 `UART8` 字段: 接收主车子状态同步, 发送 ACK, 发送辅车结果回报。
- 共享协议层只保留通用短包工具和本车视觉链路可复用的基础解析能力, 不拥有主辅业务职责。
- 主辅两端可以保持相同线格式, 但解析入口、命名和测试按角色拆开维护。


### 主车到辅车

主车通过主车侧 `UART8` 包边界发送辅车状态同步包:

```text
s,<seq>,<state>,<target>,<arg>
```

本轮找物体同步语义为:

- `state=2` 表示 `ASSISTANT_APPROACH_OBJECT`。
- `target=1` 表示 `ASSISTANT_TARGET_OBJECT`。
- `arg=1` 表示辅车找物体视觉配置。
- 辅车收到合法同步包后回复 `a,<seq>`。
- 重复同步包重复 ACK, 不重复执行清空和状态切换副作用。
- 较早同步包只 ACK, 不回退辅车子状态。

### 辅车 RT1021 到辅车 OpenART

辅车 RT1021 通过本车 `UART6` 向辅车 OpenART 同步视觉任务, 复用辅车状态同步字段:

```text
s,<seq>,<state>,<target>,<arg>
```

该同步只用于辅车本地视觉任务切换。辅车 OpenART 收到有效同步后回复 `a,<seq>`。辅车 RT1021 在本地视觉 ACK 前不把 `UART6` 速度视为新任务输出。

### 辅车 OpenART 到辅车 RT1021

辅车 OpenART 在 `ASSISTANT_APPROACH_OBJECT` 视觉任务中输出:

```text
v,<vx>,<vy>
```

目标稳定满足找到条件后, 辅车 OpenART 发送可靠事件:

```text
r,<seq>,<event>,<value>
```

其中 `event=6` 表示 `TARGET_FOUND`, `value` 表示候选目标面积。

### 辅车到主车

辅车 RT1021 收到本地视觉 `TARGET_FOUND` 后, 通过辅车侧 `UART8` 包边界向主车可靠回报:

```text
r,<seq>,<event>,<value>
```

主车收到后回复 `a,<seq>`, 并记录辅车已找到目标。该结果不直接触发搬运态。

## 主车行为

1. 主车进入 `SEARCH_OBJECT` 后维持当前搜索、等待辅车 idle、绕行流程。
2. 主车 `ORBITING` 完成后回到 `IDLE`。
3. 主车在绕行完成同一轮状态推进中生成辅车找物体同步请求。
4. 主车通过 `UART8` 可靠发送找物体同步包。
5. ACK 到达前按可靠重发间隔重发同一同步包。
6. ACK 到达后清除待确认同步包。
7. 主车收到辅车 `TARGET_FOUND` 回报后 ACK 并记录结果。
8. 主车不在本轮根据该结果启动搬运态。

## 辅车 RT1021 行为

1. 辅车默认仍从 `ASSISTANT_FOLLOW` 启动。
2. 收到 `ASSISTANT_IDLE` 时保持现有 idle 行为。
3. 收到 `ASSISTANT_APPROACH_OBJECT` 时:
   - 记录当前子状态和目标。
   - 清空 `UART8` 前馈速度缓存。
   - 清空 `UART6` 视觉速度缓存。
   - 写入零速度目标。
   - 向辅车 OpenART 可靠同步找物体视觉任务。
4. 本地视觉任务 ACK 到达前, 辅车保持零速度目标。
5. 在 `ASSISTANT_APPROACH_OBJECT` 中, 辅车忽略 `UART8` 速度前馈对最终速度的影响。
6. 在 `ASSISTANT_APPROACH_OBJECT` 中, 辅车使用 `UART6` 的 `v,<vx>,<vy>` 作为最终线速度输入。
7. `UART6` 不提供 `omega`, 辅车不新增视觉角速度输入。
8. 收到本地视觉 `TARGET_FOUND` 后:
   - ACK 本地视觉事件。
   - 停止线速度。
   - 锁定本轮找物体完成标记。
   - 通过 `UART8` 向主车可靠回报 `TARGET_FOUND`。
9. 找到目标后, 辅车不自行切换回 `FOLLOW` 或 `IDLE`; 后续状态仍由主车同步包决定。

## 辅车 OpenART 行为

1. 启动后默认执行当前跟随主车标记视觉任务。
2. 支持接收 `s,<seq>,<state>,<target>,<arg>` 本地视觉任务同步。
3. 收到 `ASSISTANT_FOLLOW` 时识别主车标记并输出跟随速度修正。
4. 收到 `ASSISTANT_FOLLOW` 时使用辅车现有橙色阈值识别主车色标。
5. 收到 `ASSISTANT_APPROACH_OBJECT` 且目标为 `ASSISTANT_TARGET_OBJECT` 时, 切换为红色目标物体识别。
6. 红色目标物体阈值完全复制主车 OpenART 物体搜索使用的红色阈值。
7. 找物体任务中使用红色候选目标, 依据目标中心横向误差和目标底边纵向误差生成 `v,<vx>,<vy>`。
8. 无有效目标时输出配置的前向搜索速度或零速度, 具体配置集中在视觉仓库常量中。
9. 目标进入横向、纵向和面积稳定窗口后, 创建一次 `TARGET_FOUND` 可靠事件。
10. `TARGET_FOUND` 未确认前按低频重发, 不随每帧图像重复创建新事件。

## 验收标准

- 主车绕行完成后会可靠通知辅车进入找物体阶段。
- 辅车收到找物体状态后不再继续跟随主车橙色色标。
- 辅车找物体阶段不会被 `UART8` 速度前馈带动。
- 辅车 OpenART 能从橙色色标跟随切换到红色目标物体识别并输出速度。
- 辅车红色目标物体阈值与主车红色目标物体阈值一致。
- 辅车橙色跟随阈值保持不变。
- 辅车 OpenART 稳定找到目标后可靠回报 `TARGET_FOUND`。
- 辅车 RT1021 收到本地 `TARGET_FOUND` 后停止运动并回报主车。
- 主车能收到并确认辅车找到目标结果。
- 主仓库 `tests/unit` 与 `tests/contract` 通过。
- 视觉仓库 `tests/unit` 与 `tests/contract` 通过。
- 正式文档和视觉仓库 README 改动作为 Task 7, 等待用户单独要求执行。

## 板端确认项

- 主车绕行结束时 `UART8` 能观察到找物体同步包。
- 主车和辅车分别使用各自角色内的 `UART8` 包边界, 不依赖共享 `uart8_packet.py`。
- 辅车收到同步后能观察到本车 `UART6` 发给 OpenART 的同步包和 ACK。
- 辅车在找物体阶段不再响应主车速度前馈。
- 辅车视觉能识别与主车相同的红色目标物体。
- 辅车找到目标后能够停住并向主车回报。
