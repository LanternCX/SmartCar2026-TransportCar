# 项目方向

## 文档边界

本文件只维护项目方向、路线目标和外部事实。具体状态编号、协议字段、控制流程和运行细节以代码、注释和行为测试为准。

## 总目标

- 第一目标: 形成可连续运行的双车协同搬运路线，并稳定完赛。
- 第二目标: 在稳定完赛基础上逐步提速。

## 路线选择

- 采用主辅协同，两台全向车底盘都参与运动。
- 主车负责环境理解、目标搜索、任务决策、状态切换和协同编排。
- 辅车负责跟随协作、执行配合和状态回传。
- 项目路线由寻找态状态机集和搬运态状态机集组成。
- 主车维护唯一任务决策主线，避免多处动作仲裁。
- 主辅通信和速度前馈是正式主线能力。
- 视觉输入按阶段理解: 寻找阶段服务主车搜索和辅车跟随，搬运阶段服务物体保持、构型推进与避障。

## 硬件与链路事实

- 底盘形态: 主车和辅车各一台全向车底盘。
- 视觉分工: 主车安装两颗正交视角摄像头；辅车车体提供可识别标记，辅车底盘不处理图像数据。
- 主辅链路: `UART8` 直连，用于速度前馈、辅车子状态同步和辅车结果回报。
- 本地视觉链路: 两台车各自使用本车 `UART6` 连接本车 OpenART。
- 调试链路: `UART3` 接入 REPL，用于板端日志和现场调试。
- 边界检测: 灰度传感器服务搬运收尾确认。

## 竞赛策略

- 优先成功率，不追求早期极限速度。
- 优先连续完成能力，不追求单次最快。
- 优先可恢复能力，避免一次异常导致全局失败。
- 速度优化不能破坏稳定完赛能力。
- 对福来轮底盘而言，方向保持是基础能力。

## 阶段目标

- 可验证: 主辅高速通信稳定，速度前馈能增强辅车跟随。
- 可闭环: 寻找态和搬运态具备可重复的最小闭环。
- 可连续: 多目标之间能稳定切换，角度分支和避障插入可控。
- 可提速: 在不降低成功率前提下缩短搜索、切换、搬运和绕障耗时。
