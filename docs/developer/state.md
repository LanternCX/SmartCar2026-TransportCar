# 状态机定义

## 1. 定位

本文件定义全局状态机在串口协议中的编号、事件和同步语义。

串口报文格式见 [串口通信协议](protocol.md)。协议只负责传输 `state`、`target`、`arg`、`event` 等字段，本文件负责说明这些字段的状态机含义。

## 2. 状态所有权

- 全局状态机由主车维护。
- 主车通过串口协议中的 `s` 包同步状态。
- 辅车和视觉端接收状态后切换本地任务。
- 辅车和视觉端通过 `r` 包回报事件或结果。
- `r` 包不直接改变全局状态，全局状态切换只由主车发出的新 `s` 包完成。

## 3. 状态同步字段

状态同步包格式：

```text
s,<seq>,<state>,<target>,<arg>
```

字段含义：

| 字段 | 含义 |
| --- | --- |
| `seq` | 状态同步编号，用于 ACK、重发和去重 |
| `state` | 全局状态编号 |
| `target` | 当前状态使用的目标编号 |
| `arg` | 当前状态的短参数 |

## 4. 全局状态编号

| `state` | 名称 | 含义 |
| --- | --- | --- |
| `0` | `IDLE` | 空闲，底盘不执行状态机任务 |
| `1` | `SEARCH_FROM_EDGE` | 从边线向场地中部搜索目标 |
| `2` | `FOLLOW_MASTER_MARKER` | 辅车跟随主车侧标 |
| `3` | `LOCK_OBJECT` | 锁定当前目标物体 |
| `4` | `MASTER_ALIGN_OBJECT` | 主车调整到目标物体的合适角度 |
| `5` | `ASSISTANT_ALIGN_OBJECT` | 辅车跟进并调整到目标物体的合适角度 |
| `6` | `TRACK_OBJECT` | 两车各自跟随当前目标物体并维持速度前馈 |
| `7` | `WAIT_PEER` | 等待对端到位或等待对端事件 |
| `8` | `STOP` | 停止状态机任务并输出停止量 |

## 5. 目标编号

| `target` | 名称 | 含义 |
| --- | --- | --- |
| `0` | `NONE` | 无目标 |
| `1` | `OBJECT` | 当前搬运目标物体 |
| `2` | `MASTER_MARKER` | 主车侧标 |
| `3` | `EDGE_LINE` | 边线 |

具体颜色、类别或视觉识别方式由视觉端在当前状态下解释，不写入串口协议字段名。

## 6. 状态参数 `arg`

`arg` 是状态相关短参数，固定为 `i16`。

| `state` | `arg` 含义 |
| --- | --- |
| `IDLE` | 固定为 `0` |
| `SEARCH_FROM_EDGE` | 搜索方向或搜索档位 |
| `FOLLOW_MASTER_MARKER` | 跟随距离档位 |
| `LOCK_OBJECT` | 目标筛选参数 |
| `MASTER_ALIGN_OBJECT` | 目标角度或角度档位 |
| `ASSISTANT_ALIGN_OBJECT` | 目标角度或角度档位 |
| `TRACK_OBJECT` | 速度前馈档位 |
| `WAIT_PEER` | 等待条件编号 |
| `STOP` | 固定为 `0` |

## 7. 事件编号

事件回报包格式：

```text
r,<seq>,<event>,<value>
```

事件编号：

| `event` | 名称 | 含义 |
| --- | --- | --- |
| `0` | `NONE` | 无事件 |
| `1` | `RUNNING` | 当前状态执行中 |
| `2` | `DONE` | 当前状态条件满足 |
| `3` | `FAILED` | 当前状态失败 |
| `4` | `WAITING_PEER` | 当前端正在等待对端 |
| `5` | `TARGET_LOST` | 目标丢失 |
| `6` | `TARGET_FOUND` | 目标发现 |
| `7` | `ALIGNED` | 角度或位置调整完成 |
| `8` | `ARRIVED` | 到位 |

`value` 是事件附加值，含义由当前 `state` 和 `event` 共同决定。

## 8. 状态跳转原则

- 主车接收事件后判断是否切换全局状态。
- 视觉端只提供观测和事件，不维护全局状态。
- 辅车只执行已同步状态，并回报本地执行事件。
- 主车等待辅车或视觉端时，使用 `WAIT_PEER` 状态或保留当前状态并等待指定事件。
- 状态切换必须通过新的 `s` 包同步，不能通过 `v`、`o` 或 `r` 包隐式切换。
