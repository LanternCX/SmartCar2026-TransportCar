# 电控与运行外部约定

## 文档边界

本文件只维护代码外的运行约定、硬件事实和容易误判的边界。控制流程、状态切换、参数值和模式细节以代码、注释和行为测试为准。

## 启动约定

- 正式入口是 `src/main.py`; 不按按钮进入正式运行脚本。
- 长按 `C14` 上电进入参数辨识脚本。
- 长按 `C15` 上电进入陀螺仪校准脚本。
- 测试模式下不按按钮进入板端测试入口。
- 主车和辅车身份由车号读取结果决定, 不由启动按钮决定。

## 硬件与存储约定

- 主车和辅车使用各自硬件接线映射, 底盘控制内核保持统一。
- 上电低压保护按车辆身份选择阈值: 主车 `3.7V`, 辅车 `3.7V`。
- `UART3` 用作 REPL 与现场调试链路。
- `UART8` 用作主辅直连链路。
- 两台车各自用本车 `UART6` 连接本车 OpenART。
- 陀螺仪零飘结果保存到 `/flash/gyro_offset.txt`。
- 电机辨识结果保存到 `/flash/ident_params.txt`。

## 调试取舍

- 状态到达但车辆未动作时, 先区分“目标未下发”和“目标被后续输入覆盖”。
- 高频控制链和通信调度链避免持续打印和函数内重复导入。
- 板端性能问题先做低频分段计时, 收口前删除临时诊断输出。
