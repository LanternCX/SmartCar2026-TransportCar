# Conventions

- 仓库新建文档、代码注释、Skill 和 Serena memory 使用中文。
- 文档和注释不镜像当前代码行为; 只补代码与 git log 难以稳定还原的原因、约束、取舍和外部事实。
- 硬件相关开发不得猜引脚、串口、电平、接线或设备行为; 仓库正文缺失时先查证, 仍缺失则问用户。
- 重构不保留兼容层; 若测试只是在保护兼容层, 先删除或调整测试再重构。
- 参数测试避免写死无依据数值; 有依据的参数用范围或枚举约束, 其余动态引入。
- 不写不必要的兜底代码; 只有真实值得承接的失败路径才加兜底。
- 编码时维护必要注释, 编码结束后同步维护相关文档; 文档改动只做规则检查, 不用 TDD。
- MicroPython 热路径避免函数内重复动态导入和高频诊断输出; 诊断日志收口前删除, 用回归测试保留结论。
- 运行主线避免依赖桌面 Python 便利写法中板端不稳定的部分, 尤其要关注字节编解码和部分带名字调用方式。
