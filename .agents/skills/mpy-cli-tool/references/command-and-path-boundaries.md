# mpy-cli 命令与路径边界入口

- 正式来源仓库：@../mpy-cli-dev
- 想先看命令总览、参数说明与无交互用法时，先看 `@../mpy-cli-dev/README.md`
- 想确认 `source_dir`、`device_upload_dir`、`.mpyignore`、上传范围与编译开关边界时，优先核对 `@../mpy-cli-dev/README.md` 中的 `mpy-cli config`、`mpy-cli plan`、`mpy-cli deploy`、`mpy-cli upload`、`mpy-cli run`、`mpy-cli delete`、`mpy-cli tree` 章节
- 想确认运行目录、配置文件与工程边界时，再看 `@../mpy-cli-dev/docs/developer-guide.md`
- 部署前默认先按仓库说明执行 `mpy-cli list` 与 `mpy-cli plan`
