# 参考文档来源与质量入口

- 本页偏来源与质量复核: 回答“这份文档从哪里来、正式放在哪里、复核时要看哪些事实是否可信”。
- `reference-sync` 不维护正式正文，这里只负责来源登记、追溯线索和质量复核入口。
- 想看文档来源、正式落点与同步触发条件，先读：`references/source-registry.md`
- 想看持续维护对象是否齐全、每次需要复核哪些质量项，再联读：`references/maintenance-checklist.md`
- 涉及外部题面资料时, 只核对 `docs/problem_statement/README.md` 中的链接是否仍可作为入口。
