# 参考入口同步规则

- 本页偏何时同步与同步后检查: 回答“什么情况下必须更新、更新后至少要补查哪些对象和检查项”。
- `reference-sync` 只维护来源登记与维护清单，不承接 `mpy-cli`、协议正文或题面正文。
- 外部题面资料不导入仓库, 只在 `docs/problem_statement/README.md` 维护链接入口。
- 更新任何正式正文时，必须同步检查：`references/source-registry.md`、`references/maintenance-checklist.md`
- 想确认某类变更是否达到同步触发条件，先读：`references/source-registry.md`
- 想确认同步完成后必须补查哪些对象、入口和维护项，再读：`references/maintenance-checklist.md`
- 涉及外部题面链接时, 只更新 `docs/problem_statement/README.md` 和必要来源登记。
