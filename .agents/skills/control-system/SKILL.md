# Purpose
规范控制算法的开发、调试和优化流程，确保控制系统的稳定性、准确性和可维护性。

# When to Use
- 实现新的控制算法或滤波器
- 调试控制不稳定或振荡问题
- 优化控制性能（响应速度、精度）
- 添加新的运动模式或控制模式

# Control System Architecture

## 1. Control Hierarchy
```
位置环（外环）→ 速度环（内环）→ 电机输出
     ↓               ↓              ↓
  里程计反馈      编码器反馈      PWM 占空比
```

## 2. Control Modes
- **速度模式**：直接指定目标速度，持续运动
- **位置模式**：指定目标位置，自动规划轨迹并锁定
- **角度保持模式**：角速度接近 0 时自动激活，保持航向角

## 3. Coordinate Systems
- **车身坐标系**：X（横向右）、Y（纵向前）、W（顺时针旋转）
- **世界坐标系**：固定参考系，通过里程计维护
- **轮子坐标系**：三轮独立的速度控制

# Development Guidelines

## PID Controller Design
1. **参数辨识**：
   - 运行 `pid_identify.py` 获取电机特性
   - 结果保存在 `/flash/ident_params.txt`
   - 包含增益 K 和时间常数 tau

2. **PID 参数配置**：
   - 位置环：纯 P 控制，输出为目标速度
   - 速度环：PD 控制 + 二次 P 项，输出为 PWM
   - 航向环：PID 控制，输出为角速度补偿

3. **前馈补偿**：
   - 基于辨识参数预测 PWM
   - 减少稳态误差和响应延迟
   - 公式：`pwm = K * target_speed * (1 + tau * d_target_speed)`

4. **抗积分饱和**：
   - 设置积分项上下限
   - 使用条件积分（误差大时不积分）
   - 输出饱和时停止积分累加

## Kinematics & Odometry
1. **运动学正解**：
   - 输入：三轮轮速
   - 输出：机器人速度（vx, vy, omega）
   - 实现：`OmniKinematics.forward()`

2. **运动学逆解**：
   - 输入：机器人速度（vx, vy, omega）
   - 输出：三轮轮速
   - 实现：`OmniKinematics.inverse()`

3. **里程计积分**：
   - 基于编码器速度和控制周期
   - 维护位置（x, y）和航向角（yaw）
   - 定期重置避免累积误差

4. **坐标变换**：
   - 车身坐标 → 世界坐标：旋转矩阵
   - 相对位移 → 绝对位移：基于当前位姿

## Filter Design
1. **编码器滤波链**：
   ```
   原始脉冲 → 中值滤波 → 双窗口线性回归 → 差分限幅 → 速度输出
   ```

2. **IMU 滤波**：
   - 陀螺仪：低通滤波 + 零飘补偿
   - 加速度计：仅用于初始化（不积分位置）
   - 姿态解算：四元数积分

3. **滤波器参数调优**：
   - 低通滤波器：`alpha` 越大响应越快但噪声越大
   - 中值滤波器：窗口越大越平滑但延迟越大
   - 差分限幅：限制单周期最大变化量

# Tuning Process

## Step 1: Hardware Calibration
1. 运行 `calibrate_gyro.py` 校准陀螺仪零飘
2. 运行 `pid_identify.py` 辨识电机参数
3. 验证编码器读数方向正确
4. 验证电机方向符合右手系

## Step 2: Inner Loop (Speed Control)
1. 禁用位置环，只测试速度环
2. 给定恒定目标速度，观察响应
3. 调整 P：增大 P 提高响应速度，过大会振荡
4. 调整 D：增大 D 抑制振荡，过大会噪声放大
5. 前馈增益：基于辨识结果，微调补偿

## Step 3: Outer Loop (Position Control)
1. 启用位置环，给定小步长位移
2. 调整 `POS_KP`：增大加快到达速度
3. 调整 `POS_MAX_SPEED`：限制最大速度
4. 调整 `POS_TOLERANCE`：位置锁定容差

## Step 4: Yaw Control
1. 测试角度保持模式（给定 omega=0）
2. 调整 `YAW_KP/KI/KD`：类似速度环调参
3. 验证无漂移且能抵抗外部扰动

## Step 5: Integration Test
1. 测试复杂轨迹（组合 x, y, angle）
2. 测试相对位移命令
3. 测试运动锁定机制
4. 测试模式切换流畅性

# Common Issues & Solutions

## 问题 1：控制振荡
**症状**：电机抖动，速度来回振荡
**原因**：
- P 参数过大
- 滤波不足，噪声被放大
- 控制周期不稳定

**解决**：
- 减小 P 参数，增大 D 参数
- 增强滤波器（低通或中值）
- 检查控制周期是否稳定在 5ms

## 问题 2：响应迟缓
**症状**：给定速度后很久才达到
**原因**：
- P 参数过小
- 滤波延迟过大
- 前馈增益不足

**解决**：
- 增大 P 参数
- 减小滤波器窗口
- 调整前馈增益

## 问题 3：稳态误差
**症状**：速度或位置无法准确到达目标
**原因**：
- 缺少积分项（速度环）
- 位置环增益过小
- 前馈不准确

**解决**：
- 速度环添加小的 I 项
- 增大位置环 KP
- 重新辨识电机参数

## 问题 4：航向角漂移
**症状**：长时间运行后航向角偏离
**原因**：
- 陀螺仪零飘未校准
- 积分累积误差

**解决**：
- 重新运行 `calibrate_gyro.py`
- 定期重置里程计（reset 命令）

## 问题 5：轮子打滑
**症状**：位置不准，运动轨迹偏离
**原因**：
- 目标速度过大
- 加速度过大
- 地面摩擦力不足

**解决**：
- 降低 `POS_MAX_SPEED`
- 添加加速度限制（轨迹规划）
- 更换更好的地面或轮子

# Testing Checklist
- [ ] 单轮速度控制测试（每个轮子独立）
- [ ] 三轮协调控制测试（前进、后退、平移、旋转）
- [ ] 速度模式测试（不同速度组合）
- [ ] 位置模式测试（绝对位置、相对位置）
- [ ] 角度保持测试（抗扰动能力）
- [ ] 运动锁定测试（防止命令累加）
- [ ] 模式切换测试（速度 ↔ 位置）
- [ ] 边界条件测试（最大速度、最小速度、零速度）
- [ ] 长时间运行测试（航向角漂移）

# Parameter Documentation
- 所有控制参数集中在 `config/params.py`
- 每个参数必须有注释说明含义和单位
- 调参记录应该记录在代码注释或单独文档
- 不同地面或配重可能需要不同参数集

# Deliverables
- 稳定可靠的控制算法实现
- 完整的中文文档和注释
- 调参过程和结果记录
- 测试验证报告
