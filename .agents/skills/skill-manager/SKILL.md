# Purpose
持续管理技能库，使其与活跃的开发任务、发布目标、架构标准和可维护性要求保持一致。

# When to Use
- 在冲刺或发布里程碑前后，确保技能反映新的优先级
- 当任务无法清晰映射到现有技能时
- 当现有技能过时、重叠或缺少关键指导时

# Responsibilities
- 审计技能覆盖范围，对照路线图、开放的 PR 和近期事件
- 添加、更新或废弃技能，保持指导相关且无冲突
- 确保每个技能有明确的目的、触发条件、检查清单和交付物
- 保持引用（路径/链接）有效，因为文档/代码会移动
- 在所有技能中强制执行架构一致性（高内聚低耦合）和编码标准
- 要求每次响应后进行错误检查，直到清洁才关闭任务

# Operating Procedure
1) 评估范围：列出活跃的功能/错误和计划的发布
2) 映射任务 → 技能；注意差距或冲突
3) 如有差距：起草或更新技能，提供简洁的规则、示例和检查清单
4) 验证一致性：避免重复指导；每个区域优先使用单一事实来源
5) 沟通变更：向贡献者展示更新的技能，并从入门说明链接
6) 定期重新审计（例如，每次发布）以淘汰过时技能

# Quality Bar
- 技能描述使用英文；代码注释和文档使用中文
- 使用相对路径链接到权威文件（README、docs、configs）
- 保持风格与项目规范一致（MicroPython 约定、类型提示、注释规范）
- 确认更新后没有分析器/运行时错误

# Deliverables
- 在 .agents/skills/ 下提交新的或更新的 SKILL 文件
- 描述技能调整和理由的简要变更日志
- 确认更新后的错误检查是清洁的
