# Skill 迁移检查清单

本清单属于 Agent 私有方法论, 用于把旧 Skill 或分散正文迁入当前结构, 不是用户主 review 正文。

## 迁移前确认

- 先确认目标 Skill 的职责边界, 不把实现规则、评审规则、写作方法论混在同一个入口
- 先阅读 `references/writing-rules.md`, 再决定采用哪一种 Skill 设计模式
- 先盘点现有正文、引用页和资产文件, 明确哪些内容是真正文, 哪些只是路由页

## 迁移执行清单

- 先逐条列出旧规则, 禁止只写一句概括后直接删旧文件
- 合并重复入口时, 必须写清旧页并入哪一个新页, 避免规则在重构中丢失
- 主 `SKILL.md` 只保留用途、边界和最少路由, 不重复堆放长正文
- `references/` 只保留有明确场景差异的入口, 没有差异就合并
- 若正文只服务 Agent 内部执行, 应迁入 Skill 私有体系, 不再放在用户主 review 正文路径

## 迁移后自检

- 确认旧正文路径已删除或完成并入, 不保留过期镜像
- 确认 references 数量已经收缩到最少可用集合
- 确认所有被迁移条目都已在盘点表或并表清单中标记为 `已完成`
- 确认新的入口描述清楚说明: 哪些给 Agent 用, 哪些才是用户需要人工 review 的正文
