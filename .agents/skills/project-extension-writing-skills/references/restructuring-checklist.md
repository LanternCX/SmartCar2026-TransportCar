# Skill 结构清理检查清单

本清单用于整理分散正文、重复规则、过时入口和历史性表述。

## 清理前确认

- 确认目标 Skill 的职责边界，不把实现规则、评审规则和写作方法论混在同一个入口
- 阅读 `references/writing-rules.md`，再决定采用哪一种 Skill 设计模式
- 盘点现有正文、引用页和资产文件，标记事实源、路由页、模板和可合并内容
- 标记历史性口吻、重复段落、过时入口和不能路由到当前事实源的内容

## 清理执行清单

- 逐条列出待整理规则，禁止只写一句概括后直接删除内容
- 合并重复入口时，记录来源页、目标页和保留后的唯一职责
- 主 `SKILL.md` 只保留用途、边界和最少路由，不重复堆放长正文
- `references/` 只保留有明确场景差异的入口；没有差异就合并
- Agent 内部执行知识放入 Skill 私有体系；用户需要人工 review 的正文保留在用户可审阅入口
- 删除迁移解释、版本对比、临时状态说明和带时态对比的历史性表述

## 清理后自检

- 确认合并后的规则都有明确正式落点
- 确认 references 数量已经收缩到最少可用集合
- 确认新入口说明清楚：哪些给 Agent 执行，哪些给用户人工 review
- 确认所有链接、路径和事实源能路由到当前仓库文档或当前代码
