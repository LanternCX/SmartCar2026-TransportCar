## 遥控协议

支持使用键值对 (Key-Value) 格式进行控制。

推杆指向的方向是 `y+`。

其余单位方向遵循右手系。

也就是 `x+` 是右移，`w+` 是顺时针旋转。

### 键值对格式

格式示例：`dx=10, dy=20, angle=90`

| 参数标签 | 说明 | 单位 | 备注 |
| :---  | :--- | :--- | :--- |
| **vx**  | 机器人坐标系 X 轴向速度 | 脉冲/周期 | 速度控制模式 |
| **vy**  | 机器人坐标系 Y 轴向速度 | 脉冲/周期 | 速度控制模式 |
| **x**   | 世界坐标系 X 目标位置 | m (米) | **位置模式 (绝对)**：指定绝对位置 |
| **y**   | 世界坐标系 Y 目标位置 | m (米) | **位置模式 (绝对)**：指定绝对位置 |
| **dx**  | 相对位移 X | m (米) | **位置模式 (相对)**：在当前位置叠加增量 |
| **dy**  | 相对位移 Y | m (米) | **位置模式 (相对)**：在当前位置叠加增量 |
| **omega** | 目标角速度 | rad/s | **速度模式**：指定旋转速度。若速度趋近 0，进入角度保持模式。 |
| **angle** | 目标角度 | deg (度) | **位置模式 (绝对)**：指定绝对角度。 |
| **d_angle** | 相对角度 | deg (度) | **位置模式 (相对)**：在当前目标角度上叠加增量。 |
| **reset** | 重置状态 | - | 发送 `reset` 或 `reset=1`：将里程计位置(x,y)及航向角归零。 |
| **print** | 打印字符串 | - | 发送 `print=Hello World`：由 uart6 接收并转发到 uart3 打印。 |

### 锁定机制 (Locking Mechanism)

为了确保相对运动指令的准确执行，避免基于非预期的中间位置叠加增量，系统引入了锁定机制：

1.  **触发锁定**：当发送相对运动指令（`dx`, `dy`, `d_angle`）时，系统进入**锁定状态**。
2.  **锁定表现**：锁定期间，系统会忽略后续发送的**相对运动指令**，并返回 `Command Ignored (Locked)`。
3.  **解除锁定**：
    *   **到达目标**：当车辆到达目标点且误差在容差范围内（位置 < 5cm，角度 < 5°）时，系统自动解锁。
    *   **指令覆盖**：发送绝对位置指令（`x`, `y`, `angle`）或速度指令（`vx`, `vy`, `omega`）会**立即解锁**并执行新指令。
    *   **状态重置**：发送 `reset` 指令会重置所有状态并解锁。

### 信息查询 (? + token)

通过发送 `? + token` 的形式向 `uart6` 查询当前运行状态。

| 查询 Token | 返回信息 | 备注 |
| :--- | :--- | :--- |
| **?pos** | `?pos=x,y,yaw` | 返回当前世界坐标和航向角 |

> 注意：
> 1. `x/y/dx/dy/angle/d_angle` 为位置控制逻辑，`vx/vy/omega` 为速度控制逻辑。
> 2. 如果同时发送位置和速度指令，位置指令控制逻辑优先级更高。
> 3. 里程计基于轮径 60mm，减速比 1:30，编码器 7ppr 计算。
