## 遥控协议

支持使用键值对 (Key-Value) 格式进行控制。

### 键值对格式

格式示例：`dx=10, dy=20, angle=90`

| 参数标签 | 说明 | 单位 | 备注 |
| :---  | :--- | :--- | :--- |
| **vx**  | X轴方向速度 | 待定 (PWM/cm/s) |  |
| **vy**  | Y轴方向速度 | 待定 (PWM/cm/s) |  |
| **omega**  | 目标角速度 | rad/s (待定) | **速度模式**：指定旋转速度。若同时未指定 angle，且 omega 接近 0，则进入角度保持模式。 |
| **angle**  | 目标角度 | deg (度) | **位置模式 (绝对)**：指定绝对角度。优先级高于 omega。 |
| **d_angle**  | 相对角度 | deg (度) | **位置模式 (相对)**：在当前目标角度上叠加增量。优先级高于 angle。 |

> 注意：`angle` / `d_angle` 为位置环控制，`omega` 为速度环控制。如果同时发送，位置环控制优先级更高。
